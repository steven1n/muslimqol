# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :---: |
| 0.1.x (Minecraft 1.21.1) | :white_check_mark: |
| < 0.1.0 | :x: |

---

## Reporting a Vulnerability

If you discover a security vulnerability or exploit in MuslimQoL (such as arbitrary command execution, server crash vectors, or item duplication bypasses), please report it responsibly and privately.

### Preferred Method
Please use [GitHub Private Vulnerability Reporting](https://github.com/steven1n/muslimqol/security/advisories/new) via the Security Advisories tab of this repository.

### Public Disclosure
Please do **not** open public GitHub issues or publicly post details of unpatched security vulnerabilities until the maintainers have had an opportunity to address the issue and publish a fix.
